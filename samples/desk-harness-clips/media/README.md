# Recordings for desk-harness-clips

Record with the laptop webcam, the clip board upright at 400 mm (closer, not farther: the outer
clips are at 16.6 px from 400 mm — the limit):

    torquesense --config config\station_desk2.yaml --record samples\desk-harness-clips\media\correct.mp4

| File | Perform |
|---|---|
| `correct.mp4` | press the cable into all five clips, any order · plug in · cover on |
| `cover_over_open_clip.mp4` | leave clip 2 open, plug in, cover on |
| `plug_not_mated.mp4` | all clips closed, do not plug in, cover on, wait 45 s |
