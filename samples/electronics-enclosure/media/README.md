# media — schematic recordings of every trace

Generated by `python synth/sample_media.py` (docs/adr/0012). For each trace in `../traces/`:

| File | What it is |
|---|---|
| `<trace>.mp4` | every frame of the cycle at 30 fps, drawn from the trace: one tile per camera, every inspection point at its CAD-projected position, its colour its state (ring = first state, grey = a middle state, yellow = the last state; a glove = occluded) |
| `<trace>/frame_NNNN.png` | the first frame of each state change, and frame 0 |
| `<trace>/frames.json` | for each image: frame, time, and the state every point must read as |

These are drawings, stamped as such on every frame — not camera footage and not renders.

Verify them through the engine's perception path, frame by frame:

    torquesense --sample samples\electronics-enclosure --verify-media all            # every video and keyframe
    torquesense --sample samples\electronics-enclosure --verify-media correct --frames-csv frames.csv
    torquesense --sample samples\electronics-enclosure --classify-image samples\electronics-enclosure\media\correctrame_0000.png

Each video must raise exactly the violations its trace expects (spec Section 12). Real recordings,
once made, replace these files under the same names and must pass the same check.
